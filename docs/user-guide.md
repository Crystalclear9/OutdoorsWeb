# 使用指南

## 账号与业务

- 企业：注册、登录、退出、资料维护、修改密码；修改密码后全部设备会话失效。
- 验证码：注册和登录均需填写 6 位数字 PNG 图片验证码；点击图片换一张。验证码由服务端生成并绑定浏览器，5 分钟过期，答错或验证成功即作废，不能重复使用；密码或网络错误后前端换图并保留其他输入。图片验证码不代表邮箱、手机号或企业身份已核验。
- 超级管理员：首次由服务端配置创建，拥有全部管理权限；通过“授权管理”创建工作人员并分配独立职责。普通注册只能获得企业身份，无法自行提升权限。
- 工作人员：按需授予企业申请审核、公告管理、企业账号管理或日志查看权限。界面菜单和 API 使用同一权限定义；没有授权即使直接调用接口也会拒绝。
- 账号恢复：企业账号管理员只能管理企业。超级管理员可管理工作人员，受保护的超级管理员账号不能在网页中降权、停用或重置。临时密码仅显示一次，首次登录强制修改。
- 恢复密码：由管理员核验身份后重置。本版不发送验证邮件，也没有无验证的自助重置入口。
- 申报：地点统一为“大活A座平台”，无需选择具体桁架位置。搭建方电话可填写手机或国内区号座机，支持分机，如 `027-87540000-1234`。填写企业联系人、企业手机、搭建方联系人和联系电话，选择最长 3 天（含起止日期）的布展日期，上传 3 MB 以内 JPG/PNG/WebP 桁架设计图。提交期间锁定字段，失败保留输入并恢复编辑。
- 摆放区域示意：企业和游客可查看平台允许摆放区域。示意图不按实际比例绘制，不代表位置预订；具体边界以现场标识和管理人员指引为准，出入口及消防通道必须畅通。
- 审核：管理员核对桁架宣传内容、设计方案、日期和搭建方联系方式，通过或退回；退回原因必填。详情弹窗只有设计图成功显示后才允许通过，读取或解码失败可在原位重新加载。不要求企业选位，多份同日内容可以分别审核通过。
- 过期待审：开始日期早于当前北京时间日期且仍未审核的申请，管理员显示“过期未审核”，企业显示“未通过”并说明过期原因。不伪造审批人或人工审核时间，不能再批准、退回或撤回；企业应重新提交有效日期的申请。统计和状态筛选使用相同口径。
- 取消：企业可取消自己的尚未开始或当日开始的已通过申请，填写原因并确认；已开始但未结束的活动由有审核权限的管理员处理。已结束的记录保留历史。取消检查最新版本，相关待审改期一并撤回。
- 改期：企业在未开始的生效申请详情中提出日期调整，沿用原企业与搭建方资料和设计图。待审期间保留原申请，退回或撤回不影响原申请，批准后原子替换。每条原申请只允许一份待审改期。
- 审批台：默认待办队列与材料审阅并排显示，支持搜索、排序、连续审阅、快捷退回原因和批量处理；处理后自动切换下一条。历史中可按提交日期、审批人和状态筛选，包括“过期未审核”。
- 批量处理：操作前核对本页选中的企业、日期和材料，明确确认后提交；统一退回原因必填。每批最多 50 条，页面每页 15 条。版本变化、已处理或已过期的记录逐条拒绝并说明，不覆盖其他人已完成的结果。
- 历史：企业只能查看自己的申请；管理员按权限读取。旧位置预约、收费和电话记录保留，不将旧记录伪装为新内容审核。旧记录缺失搭建方信息时显示“历史未登记”。
- 企业工作台：仅跟进申请、审核结果和公开公告，不提供“通知与缴费办理”，也不显示付款流水或费用面板。
- 状态统计：工作台的待审、已通过和未通过卡片直达对应分类；管理员“过期未审核”直达历史中过期待审列表，企业端仍归入未通过。
- 管理员工作台：处理企业申报、管理公告和账号。场地开放安排不再提供，相关暂停/恢复写接口已退役；既有历史记录不因界面调整而清除。
- 扫码入口：点击页头问号打开指南，可下载当前网站公开入口二维码；二维码不携带地址中的查询参数或片段。本机地址不能直接分享给其他设备，需先从手机可访问的完整服务地址打开网站。二维码不能让 Pages 自动获得后端能力。
- 公告：管理员在公告页直接填写标题和正文发布，可置顶，支持 Ctrl+Enter；发布失败保留输入。已发布内容支持编辑和删除，编辑保存期间锁定标题、正文及置顶选项，企业与游客公开阅读。
- 管理员消息：新申请向审核人员形成待办。新内容审核申请不生成企业缴费、费用核定或结果电话待办，企业在“我的申请”读取审核结果。
- 日志：保留账号与业务操作，按日期、邮箱、操作代码或关联编号分页查询，可导出当前页 CSV；日期按北京时间解释。账号管理也改为服务端搜索与分页，不再截断为最近 1000 个账号。

审批台变更搜索、排序或页码后，只有当前条件读取成功才开放单条和批量审批。刷新读取期间暂停操作，失败后隐藏旧队列和材料；点击“刷新”成功后才能继续。同一申请的审核意见在刷新失败及重试期间保留；批量选中记录仍携带原版本，其他人员已处理的申请由服务端拒绝覆盖。

操作日志变更查询条件或刷新时，暂时隐藏旧结果并关闭导出；读取失败或日期范围无效时同样禁止导出。点击“刷新日志”重新读取成功后，导出内容才对应当前筛选和页码。已离开的旧查询错误不会覆盖新的查询结果。

历史审计归档读取或翻页失败时隐藏旧下载列表，点击“刷新归档”可在当前页重新读取；只有读取成功后才显示下载和分页入口，空归档与读取失败分别提示。

修改密码提交后，请等待结果；页头和账号页的退出入口会暂时锁定，切换页面再返回也不能重复提交。成功后退出并重新登录；失败后当前页保留输入，可核对后重试。退出重登录后，旧资料请求的迟到响应不会把页面身份切回旧账号。

账号管理变更查询条件、读取中或查询失败时暂停使用旧账号列表；点击“刷新账号”重新读取成功后，才恢复停用、启用及重置密码入口。资料回写同时检查账号版本，同一次登录中先发请求的旧响应也不能覆盖更新后的资料。

两步验证状态显示“状态待确认”时，请点击“重新读取验证状态”核对后再操作。启用已成功而后续同步失败时，本页继续保留恢复码，重试不会再次启用；关闭页面前请先保存恢复码。快速离开并重新打开登录页时，验证码会等待上一请求结束后再加载新图。

通知偏好保存及手机号绑定期间，当前卡片的勾选、绑定切换与关联操作暂时锁定，完成后恢复。偏好写入失败保留输入，可核对后重试；绑定状态读取失败时，使用“重新读取绑定与通知状态”恢复操作。绑定或解绑已保存但回读失败会明确提示，重新读取不会重复提交变更。管理员授权保存期间也会锁定权限及确认字段。

授权列表未读取成功时暂停新增、授权及账号操作，可点击“刷新授权列表”恢复。创建管理员或重置密码已成功但后续读取失败时，弹窗继续保留一次性临时密码并说明结果；“重新读取授权列表”只读取，不重复创建或重置。请先妥善记录密码再关闭弹窗。

登录设备列表读取失败时清除旧列表并暂停撤销入口，点击“重新读取登录设备”恢复。撤销已成功但刷新失败会明确提示已撤销，重试只读取最新设备，不重复发送撤销请求。

运行维护中的通知发送记录只允许操作当前查询成功读取的结果。读取失败时隐藏旧列表，可点击“刷新通知记录”恢复；核实弹窗打开期间暂停列表轮询，保存失败保留核实依据及错误，关闭弹窗后恢复读取。

## 历史办理记录

管理员可进入内部“通知与缴费办理”查看旧预约的财务、结果电话及日历。此入口不向企业开放，也不处理新的内容审核申请。旧费用核对、取消后到账和退款仍须以实际资金记录为准，详见[历史办理与费用](casework.md)。

## 场地底图与编号

当前使用 `src/AllowedArea.jsx` 的固定区域示意，不提供 29 位选择、空闲查询、日期占用或开放排期。原图和旧记录的 slot 编号仅保留历史参考，新申请中的内部兼容值不表示分配了任何具体桁架位。
