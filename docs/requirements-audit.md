## 尚需的上线验收

当前可交付 Docker 业务系统，但不能声明 PDF 的全部运营要求已经验收。真实短信/电话、QQ/微信、异机备份与告警需要自己的服务账号、凭据和联调；工作日时限和线下缴费闭环已在代码中实现；仍需维护实际日历、安排人员拨号，并按批准的收费规则填写费用。系统不能保证人工办理或真实银行到账。

此外，邮箱所有权和企业真实性尚未核验；SQLite 适用单机，多服务器须更换集中式数据库。公网需要 HTTPS、安全 Cookie、持久化密钥和实际恢复演练。完整边界见[安全文档](security.md)，外部接入步骤见[接入指南](integrations.md)。
