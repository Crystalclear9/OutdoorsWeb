## 每次发布应留下的记录

- 目标提交与镜像、配置变更项、变更负责人、验证结果和发布时间。
- 发布前数据库及密钥备份的位置、访问权限、恢复演练结果及回滚目标。
- 独立企业、审核和财务账号验收结果；真实资金核对由财务记录，不用测试凭据替代。
- 尚未启用的服务、已知限制、处理负责人和复查时间；失败时按运行维护文档定位与回滚。

当前实现以单机 SQLite 为边界，邮箱所有权和企业真实性未自动验证，未接入银行自动扣款/对账或部分退款。真实外部服务、网络层防护和独立防篡改日志也不能由代码回归证明已启用。具体边界见[安全说明](security.md)与[外部接入](integrations.md)。

完整镜像验收命令为 `npm run test:docker`，须先构建 `outdoorsweb:verify` 并启动 Linux Docker engine。它仅使用本次 UUID 容器及卷，检查首次管理员/MFA、页面资源、企业申报审批和替换容器后的资料及密钥保留；不连接正式 `.env` 或数据卷。真实环境的收费规则、日历、通信及恢复演练仍需按本表验收，不能由这个隔离 smoke 代签。
