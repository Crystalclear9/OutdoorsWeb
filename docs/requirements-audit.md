# 原始需求与当前实现核对

核对日期：2026-10-21。依据用户提供的《华中科技大学大学生活动中心户外广场企业布展预约、审核在线小程序--2026.09-》27 页 PDF，以及后续关于账号、Docker、并发、授权、审批效率、验证码和界面合并的要求。PDF 为扫描件，本轮逐页查看页面并辅助 OCR；页码按 PDF 实际页序计算。

## 本轮修正与验证

- 补上游客端实际摆放统计和逐位现场状态，接口仅公开白名单字段。
- 补上可下载的公开入口二维码，过滤查询参数和片段，并提示访问条件。
- 修复设计图异步读取竞争、非法换图残留及读取中提交的问题。
- 修复现场登记并发冲突后的重读异常，保留尚未保存的输入。
- 后端 58 项、浏览器 30 项、桌面/手机视觉回归通过。32 并发、1000 次公共读取无错误；32 条同位竞争审批仅 1 条通过。以上为隔离环境验证，不代表真实部署容量或第三方送达。

新增回归位于 `server/tests/completion.test.mjs`、`tests/completion.spec.js` 和 `tests/requirements.spec.js`。CI 另执行 Docker 构建和固定 Linux 浏览器视觉回归；结果以对应提交的工作流为准。

## 尚需的上线验收

当前可交付 Docker 业务系统，但不能声明 PDF 的全部运营要求已经验收。真实短信/电话、QQ/微信、异机备份与告警需要自己的服务账号、凭据和联调；一个工作日内电话反馈需要办理排班和超时处置；收费规则需确定后才能实现缴费闭环。

此外，邮箱所有权和企业真实性尚未核验；SQLite 适用单机，多服务器须更换集中式数据库。公网需要 HTTPS、安全 Cookie、持久化密钥和实际恢复演练。完整边界见[安全文档](security.md)，外部接入步骤见[接入指南](integrations.md)。
