# 文档目录

初次运行从[项目首页](../README.md)开始，环境变量集中在[配置说明](configuration.md)。各指南以项目根目录为命令执行位置。

| 文档                            | 内容                                             |
| ------------------------------- | ------------------------------------------------ |
| [使用指南](user-guide.md)       | 企业申报、审批台、改期、现场登记、公告和场地编号 |
| [配置说明](configuration.md)    | 环境变量、默认值、Docker 与本地开发的区别        |
| [账号与安全规则](security.md)   | 角色权限、并发约束、验证码、快捷注册和两步验证   |
| [运行维护](operations.md)       | 升级、备份恢复、管理员恢复、空间回收与故障排查   |
| [外部服务接入](integrations.md) | 短信/语音、QQ/微信、S3 加密备份与独立告警        |
| [开发与测试](development.md)    | 开发环境、命令、自动测试、视觉基线与静态发布     |
| [项目结构](architecture.md)     | 前后端模块、共享定义、测试及生成文件的归属       |
| [变更记录](../CHANGELOG.md)     | 近期功能与后端修正，及已知边界                   |

文档中的域名、管理员邮箱和密码占位符均须替换。测试账号、固定验证码和第三方模拟响应仅用于隔离测试入口，不作为正式配置。
