# 功能对应与验收边界

功能依据为《华中科技大学大学生活动中心户外广场企业布展预约、审核在线小程序--2026.09-》27 页场地业务说明，页码按 PDF 实际页序计算。

## 账号、并发与办理

- 账号、会话、申请、设计图、费用、公告和日志持久化在服务端；Pages 只提供静态入口，完整服务由 Docker 或 Node 运行。
- 企业只操作自身记录，工作人员按职责授权，收权撤销会话；管理员不能审核自己的申请。
- 待审不占位，数据库事务与触发器保证同位重叠日期只允许一条生效预约；写入检查最新版本，提交支持幂等标识。
- 取消释放位置并保留历史与退款责任；改期审核前保留原预约，批准后原子替换，费用不自动转移。
- 电话、收费、付款流水、到账、取消后到账及全额退款均有独立状态与权限；不能将流水或服务商受理当作到账、送达或接通。
- 工作台、场地查询与办理职责分开；问号打开指南，地图保持原图比例，桌面与手机均有回归。
- 验证码、MFA、限流、资源限制、审计、归档和备份恢复见[安全说明](security.md)。

## 部署与运营验收

自动回归覆盖角色、事务、竞争审批、界面异常、备份和 Docker 持久化；入口及范围见[开发与测试](development.md)和[质量说明](quality.md)。

投入运营前须确认：

1. 29 个位置、开放规则、日历、审批负责人及反馈时限符合现场安排。
2. 收费依据、收款账户、核款及退款责任明确，以独立企业、审核和财务账号完成办理。
3. 配置公网域名、HTTPS、安全 Cookie、可信代理及目标主机容量。
4. 短信、电话和第三方登录用真实账号验收；S3 备份实际下载、解密并恢复。
5. 数据库及匹配密钥离机保管，完成恢复演练、告警与故障交接。

邮箱所有权、企业真实性核验、多主机数据库及完整网络防护属于[已知限制](quality.md#已知限制)。
