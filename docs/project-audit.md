# 多代理项目复核

日期：2026-10-21。以 `de7a421` 为起点，由三个子代理分别审查后端安全与恢复、业务状态与权限、前端交互；主代理交叉检查、整合修复并运行完整验证。本次不是对真实部署环境或第三方服务的验收。

## 发现并修复

| 问题                                                        | 修正                                                                                                               | 新增回归                               |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | -------------------------------------- |
| 手动备份接受无效 MFA 密钥，可能报告成功却无法恢复验证器资料 | 复制前严格校验 64 位十六进制环境密钥或 32 字节密钥文件；校验快照完整性，数据库与密钥均完成后才发布，禁止覆盖原目标 | `server/tests/backup-audit.test.mjs`   |
| 异机上传旧快照时可能混用当前应用密钥                        | 独立快照必须使用自己的 `.mfa-key` 副本；缺失或损坏时停止上传，真实加密恢复核对密钥配对                             | 同上                                   |
| 压缩前的密钥写入失败，遗留不完整安全快照                    | 压缩前失败清理本次不完整副本；进入压缩阶段后保留完整安全备份。手动、自动和压缩备份显式限制文件权限                 | 同上                                   |
| 审核与财务看到对方才能处理的待办                            | “待跟进事项”按授权组合筛选；企业仍查看自己的完整进度                                                               | `server/tests/casework-audit.test.mjs` |
| 取消或批准改期后，财务未获原费用提醒                        | 在取消事务内向在职财务发送核款/退款消息；重复操作不重复发送，原费用不转到新申请                                    | 同上                                   |
| 跨源日历更新被浏览器预检拦截                                | 允许方法补齐 `PUT`，继续校验明确来源、会话和 CSRF                                                                  | `server/tests/http-boundary.test.mjs`  |
| 慢网切换查询日期时，把旧日占用和现场登记标成新日            | 数据绑定返回日期；加载或失败时显示待同步，隐藏旧状态并禁用申请；迟到响应不覆盖当前日                               | `tests/venue-loading.spec.js`          |
| 认证请求未完成时可离开或切换，迟到结果突然改变身份          | 密码、短信、MFA、第三方资料补全期间锁定返回和其他认证入口，失败后恢复操作                                          | `tests/auth-navigation.spec.js`        |
| 管理弹窗保存中可关闭并打开另一条，旧回调干扰新弹窗          | 账号、授权、公告的保存/删除期间锁定关闭与取消，阻止重复提交                                                        | `tests/dialog-saving.spec.js`          |

修复没有改变数据库结构版本 **7**。没有重置账号、预约、费用记录或已有密码。备份操作仍需要保管密钥并进行恢复演练；文件权限也不能限制拥有主机管理权的人。

## 检查范围

- 认证、企业归属、管理员授权、CSRF、来源检查、验证码及 MFA、短信与 OAuth 凭据消费。
- 预约竞争、审批、取消、改期、实际摆放、公告、工作日历、费用状态和通知。
- 备份、恢复、归档、维护租约、离线压缩、异机备份配对及异常收尾。
- 表单互斥、迟到响应、慢网与断网、桌面/手机布局、静态 Pages 未连接状态。
- 构建、全部接口及浏览器回归、固定视觉基线、隔离压测和 npm 依赖审计。实际数量及验证记录见[开发与测试](development.md#验证)。

整套浏览器回归增加后暴露出测试共用来源触发验证码限流的问题；现以测试专用来源隔离解决，正式验证码上限保持不变。失败诊断的共享目录也要求测试进程串行启动，防止诊断文件互相清理。

## 仍需实际环境验收

短信、电话、QQ/微信、S3 与告警仍需服务账号、正确配置和真实联调。收费依据、实际到账、拨号结果和按时反馈由机构及人员核实；系统不会把流水提交或服务商受理当作到账或接通。

当前仍使用单机 SQLite，邮箱所有权和企业真实性尚未核验，未内置完整网络层抗攻击能力。公网须配置 HTTPS、安全 Cookie、持久化密钥和恢复演练。代码审查及自动测试降低已知风险，不能证明不存在其他缺陷。完整边界见[安全文档](security.md)。
