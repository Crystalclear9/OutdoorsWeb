# 功能对应与验收边界

业务采用桁架内容审核流程，地点固定为大活A座平台。原场地业务资料作为历史参考；当前不提供具体位置预约、空闲查询或场地开放安排。

## 角色与流程

| 功能         | 当前实现与验收要点                                                                                                                           |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 三种入口身份 | Pages 阶段展示仅企业、管理员、游客；完整服务使用真实账号及服务器权限，不允许浏览器切换后台权限。                                             |
| 企业申请     | 企业资料、企业联系人和手机、搭建方联系人和联系电话、起止日期、设计图均由后端校验；最长 3 天含首尾日，图片完整解码、去元数据后保存。          |
| 固定地点     | 统一大活A座平台，提供允许摆放区域示意；不申请具体桁架位，不按默认位置进行独占审批。                                                          |
| 内容审核     | 核对宣传内容及方案，支持待办、连续和批量审批、提交日期及审批人筛选；退回必填原因，写入检查归属、授权和版本。                                 |
| 过期待审     | 开始日期早于北京时间今天，仍待审的记录：管理员显示“过期未审核”，企业显示“未通过”。筛选和统计同步，禁止继续改变审核结果，不伪造人工审批信息。 |
| 企业结果     | 我的申请及详情查看审核结果，支持有效申请撤回、取消和改期；企业无通知与缴费办理、付款流水和费用面板。                                         |
| 管理与公告   | 管理员按权限管理申请、公告、企业账号、工作人员、日志和维护；暂停/恢复场地写接口退役。                                                        |
| 历史兼容     | 旧账号、位置预约、费用、电话和审计保留；旧位置重叠保护不影响新内容审核，旧费用供内部对账，新申请不生成费用和电话待办。                       |

## 一致性与安全

- 企业只操作自己的申请和设计图，普通注册不能获得管理权限。
- 同一申请并发审核最多成功一次；独立的内容申请不因同日或内部 slot 值互相阻塞。
- 提交幂等、写版本检查、日期跨午夜重验、取消和改期事务保持有效。
- 验证码、MFA、限流、审计、备份和恢复见[安全说明](security.md)。
- Pages 展示使用虚构数据，不连接真实 API，不代替完整服务验收；参见[临时演示](temporary-showcase.md)。

## 实现与启用条件

| 范围            | 代码能力与当前边界                                                                                                                 |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 常规账号及防护  | 邮箱密码注册登录、图片验证码、密码修改、管理员恢复、职责授权、MFA 和设备撤销已实现；邮箱所有权与企业真实性仍由机构核实。           |
| 审批效率        | 待办队列、连续审阅、批量处理、材料图片门禁、状态统计直达及失败保留意见已实现；宣传内容是否合规由管理员判断。                       |
| 企业通知范围    | 新申请只在“我的申请”查看结果；账号绑定页也不提供短信或语音结果订阅。历史通知记录及接口保留兼容，不向新内容申请生成通知或费用任务。 |
| 公告与帮助      | 管理员可直接发布、编辑、置顶和删除公告；页头问号直接打开指南，指南可下载公开入口二维码。                                           |
| Docker 完整服务 | 账号、数据库、设计图及密钥的容器持久化有自动验证；目标主机、域名、HTTPS、安全 Cookie、容量及真实恢复演练仍需运行环境验收。         |
| 外部登录与通信  | 手机号、QQ/微信接入代码及隔离协议测试已实现；实际使用需要机构自己的服务账号、凭据、回调和联调，Pages 不提供这些真实能力。          |
| 允许区域        | 已提供固定地点的简化示意图，不按实际比例；现场边界和通行要求需要管理单位确认，图示不能代替现场验收。                               |
| 备份及长期运行  | 本地及加密异机备份、恢复、容量保护、日志和告警具备实现及隔离验证；真实存储、告警接收及恢复目标需要部署配置和演练。                 |

原资料中的具体桁架位查询和开放安排已由固定地点及区域示意替代；企业通知与缴费办理已移除。旧财务历史继续采用财务确认后通知的兼容流程，不自动开具新内容审核费用。当前 Pages 身份切换是明确标记待删除的阶段展示；完整服务的真实权限由后端授予。

## 运行验收

确认区域示意与现场管理口径、审批负责人和日期规则；配置公网 HTTPS、安全 Cookie、可信代理及实际容量。外部通信、第三方登录、异机备份须使用真实账号联调，并完成下载解密恢复、告警和交接。自动测试不能证明企业资料真实性或真实资金、通信结果。
